Avanço no JavaScript

Projeto desenvolvido para praticar conceitos fundamentais e intermediários de JavaScript, com foco em lógica de programação, manipulação do DOM e interação com páginas web.

📌 Sobre o projeto

O objetivo deste repositório é registrar a evolução nos estudos de JavaScript através de exercícios, testes e pequenas funcionalidades práticas.

O projeto serve como ambiente de aprendizado para:

Estruturas condicionais
Funções
Manipulação de elementos HTML
Eventos
Variáveis e arrays
Organização de código JavaScript
Integração entre HTML, CSS e JS
🚀 Tecnologias utilizadas
HTML5
CSS3
JavaScript

🎯 Funcionalidades
Interação dinâmica com o usuário
Manipulação do DOM

Exercícios práticos de lógica
📚 Objetivo de aprendizado

Este projeto foi criado para consolidar conhecimentos em JavaScript e melhorar habilidades em desenvolvimento front-end.

Durante o desenvolvimento foram praticados conceitos importantes como:

if / else
funções
eventos
arrays
objetos
atualização de elementos HTML via JavaScript
